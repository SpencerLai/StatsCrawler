# Coding Standards Directory

This directory contains documentation related to coding standards and style guidelines for the StatsCrawler project.

## Contents

- **STYLE_GUIDE.md** - Comprehensive style guide covering:
  - TypeScript conventions
  - Naming conventions (camelCase for variables)
  - Indentation rules (tabs)
  - Formatting guidelines
  - Best practices
  - Examples

## Configuration Files

The following configuration files at the project root enforce these standards:

- `.eslintrc.json` - ESLint configuration for TypeScript linting
- `.prettierrc` - Prettier configuration for code formatting
- `.editorconfig` - Editor configuration for consistent settings
- `.vscode/settings.json` - VS Code specific settings

## Quick Reference

- **Language**: TypeScript
- **Variable Naming**: camelCase
- **Indentation**: Tabs (not spaces)
- **Quotes**: Single quotes
- **Line Length**: 100 characters

## Getting Started

1. Install dependencies (includes ESLint and TypeScript):
   ```bash
   npm install
   ```

2. Lint your code:
   ```bash
   npm run lint
   ```

3. Install recommended VS Code extensions:
   - ESLint
   - Prettier - Code formatter
   - EditorConfig for VS Code
